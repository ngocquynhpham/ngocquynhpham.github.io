Folder Layout

Cấu trúc src/ chuẩn — áp dụng cho mọi loại dự án với các thư mục tuỳ chọn theo type.

Core structure (mọi loại)
src/ ├── app/ // Next.js App Router │ ├── layout.tsx // root layout + providers │ ├── page.tsx │ ├── not-found.tsx │ ├── error.tsx │ └── (routes)/ // route groups ├── components/ // shared UI components │ ├── ui/ // shadcn/ui primitives │ └── layout/ // Header, Footer, Shell ├── data/ │ └── api/ // adapters: DTO → view model │ └── feature.ts ├── lib/ │ ├── api-client.ts // base HTTP client │ ├── routes.ts // URL registry │ ├── utils.ts │ └── cache.ts // TTL / React cache helpers └── types/ └── index.ts
+ SaaS / Admin
src/ ├── app/(auth)/ // login, register... ├── app/(protected)/ // authed routes ├── lib/auth.ts // Auth.js config ├── lib/permissions.ts // RBAC helpers └── store/ └── useUserStore.ts
+ E-commerce
src/ ├── app/(shop)/ // catalog routes ├── app/(checkout)/ // checkout flow ├── store/ │ └── useCartStore.ts └── lib/stripe.ts // payment client
+ Dashboard
src/ ├── hooks/ │ ├── useMetrics.ts // useQuery wrappers │ └── useSocket.ts ├── components/charts/ └── store/ └── useFiltersStore.ts
+ Corp / SEO-heavy
src/ ├── lib/seo.ts // pageMeta() helper ├── lib/structured-data.ts ├── public/ │ └── llms.txt // GEO optional └── app/.../ └── _components/ // colocation
✅
Rule colocation: Nếu component chỉ dùng ở 1 route, đặt trong _components/ bên trong route folder. Chỉ lift lên src/components/ khi dùng ở 2+ nơi.

Server Component fetch pattern

// data/api/news.ts — Corp/ECOM import { cache } from 'react' // React cache() deduplicates per request export const getNewsList = cache(async (page = 1) => { const res = await fetch(`${API_BASE}/news?page=${page}`, { next: { revalidate: 60 } // ISR }) if (!res.ok) return { items: [], total: 0 } // graceful fallback const raw = await res.json() return newsSchema.parse(raw) // Zod validate })

TanStack Query mutation pattern

// SaaS/Admin — useMutation + invalidate const mutation = useMutation({ mutationFn: (data: CreateItemInput) => apiClient.post('/items', data), onSuccess: () => { queryClient.invalidateQueries({ queryKey: ['items'] }) toast.success('Saved!') }, onError: (err) => toast.error(err.message), })
⚠️
Đừng fetch trong useEffect. Dùng Server Component hoặc TanStack Query. useEffect + fetch bỏ lỡ loading state, race condition, và không cache được.

SEO & GEO

Áp dụng cho Corporate và E-commerce. SaaS/Admin/Dashboard thường bỏ qua panel này.

⚠️ Làm SEO sớm (Phase 3) — không để cuối. URL structure thay đổi muộn gây mất backlink và redirect phức tạp.
SEO Checklist
  • generateMetadata() per route
  • OG tags: title, description, image
  • robots.ts — allow/disallow
  • sitemap.ts — dynamic generation
  • JSON-LD: Article / Product / Org
  • 301 redirect map cũ → mới
  • noindex cho ?q=, pagination
  • Canonical URL cho duplicate
GEO (AI-first search)
  • public/llms.txt — AI bot hint
  • robots.ts: allow GPTBot, Claude-Web
  • Headings semantic và descriptive
  • FAQ schema → AI snippet
  • Entity markup (Organization)
  • Clear authorship / date metadata

pageMeta() helper pattern

// lib/seo.ts export function pageMeta(page: string, overrides = {}): Metadata { const base = seoPages[page] ?? seoPages.default return { title: base.title, description: base.description, openGraph: { ...base, url: `${SITE_URL}/${page}` }, alternates: { canonical: `${SITE_URL}/${page}` }, ...overrides, } } // page.tsx export const generateMetadata = (): Metadata => pageMeta('news', { title: 'Latest News | Brand' })

Deploy & Ops

Lựa chọn deploy theo loại dự án và trade-off.

Deploy target matrix
LoạiKhuyến nghịLý doTrade-off
🏢 Corp / Marketing Vercel hoặc EC2 standalone Edge CDN, ISR, zero config Vercel cost scale; EC2 cần ops
🚀 SaaS Vercel Edge Edge Middleware cho auth, global latency Vendor lock-in nhẹ
⚙️ Admin / Internal Nginx + Docker hoặc Vite SSG Không cần SSR, build static là đủ Phải tự quản infra
🛒 E-commerce Vercel ISR cho catalog, Edge cho cart Stripe webhook cần verify IP
📊 Dashboard Container (ECS/EKS) hoặc EC2 Cần WebSocket, long-lived connection Vercel timeout 30s cho API routes
